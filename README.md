# Research Milestone

This project was developed as part of the Research Milestone. Its purpose is to explore Swift, SwiftUI, and Supabase through the development of an iOS chore management application.

## Technologies
- **Swift & SwiftUI** – Application development and user interface
- **Swift Playgrounds** – Development environment
- **Supabase** – PostgreSQL database and REST API

## Features
- Loads and displays roommate information from Supabase.
- View chores assigned to each roommate.
- Add new chores to the database.
- Mark chores as complete or incomplete.
- Saves and updates chore information using Supabase.
